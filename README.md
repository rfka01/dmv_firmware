# DMV Firmware

New and modified firmware for the **NCR Decision Mate V** (DMV) · Neue und geänderte Firmware für die **NCR Decision Mate V**

| | |
|---|---|
| [`Keyclick/`](Keyclick/) | Keyboard controller firmware that can switch the key click off or to a faint tick, with utility for DOS, CP/M-80, CP/M-86 and CP/M-68K · Firmware für den Tastaturcontroller, die den Tastaturton abschalten oder leise stellen kann, mit Utility für DOS, CP/M-80, CP/M-86 und CP/M-68K |
| [`SYNDEMO/`](SYNDEMO/) | Keyboard controller firmware with a three-voice synthesizer and noise generator (includes Keyclick), programming interface and demo for DOS · Firmware für den Tastaturcontroller mit dreistimmigem Synthesizer und Rauschen (mit Keyclick), Programmierschnittstelle und Demo für DOS |
| [`DMVTRAK/`](DMVTRAK/) | MOD player and tracker for the DMV speaker, uses the synthesizer firmware · MOD-Player und Tracker für den Lautsprecher der DMV, nutzt die Synthesizer-Firmware |
